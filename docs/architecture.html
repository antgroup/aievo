aievo-next · Architecture

A Go multi-agent framework with parallel tool dispatch, typed streaming, and an explicit state machine — inspired by Claude Code's engineering choices.

Concurrent Tools (8× ⚡)

  • • Tool.IsConcurrencySafe() partition
  • • errgroup with MaxParallel limit
  • • Stable model-order results
  • • Benchmark: 808ms → 101ms

Explicit State Machine

  • • 8 states with named transitions
  • • ctx.Done() checked every tick
  • • Terminal reasons typed (OK / Err / Max / Cxl)
  • • Strict mode panics on illegal moves

Typed Stream + Multi-Provider

  • • Sealed StreamEvent interface (5 variants)
  • • OpenAI + Anthropic + mock
  • • PickProvider routes by model prefix
  • • Compat with Ollama / DeepSeek / vLLM

Permission Modes

  • • plan — read-only, denies mutations
  • • acceptEdits — auto-approve writes
  • • default — ask via Decider
  • • bypass — sandbox / CI only

Multi-Agent SOP

  • • Graph = read-only data, validated for cycles
  • • {{prev}} substitution between nodes
  • • OnError fallback per node
  • • 7 demo apps cover all aievo use-cases

Extensibility

  • • MCP stdio servers as tools
  • • SKILL.md markdown skills
  • • Subagent spawning via tool call
  • • Feature flags via AIEVO_FEATURE_*
